## Problem\n\nThe Gödel-encoded `QuestionGraph` (Phase 1) overflows PostgreSQL BIGINT at 6-7 DAG nodes — a useful research circuit breaker but a hard wall for enterprise-scale corpora (10,000-word incident reports, multi-day conversation trees). Phase 2 replaces this with a fractal compression pattern inspired by neural memory consolidation.\n\n## Pattern\n\nIntermediate Genie syntheses fire at semantic boundaries (section breaks, topic shifts, or when working memory approaches a configured token threshold). Each synthesis:\n1. Compresses the current working set of clauses into a dense Axiomatic summary preserving SFL metadata\n2. Flushes raw tokens from the active context window (originals stay in PostgreSQL)\n3. Carries the summary forward as the axiomatic base for the next reasoning cycle\n\nThis produces a fractal graph: each cycle compresses a detail layer into an axiomatic node; the next layer builds on top. Depth is unbounded because layers reference compressed summaries semantically, not arithmetically.\n\n## What it replaces\n\n- `QuestionGraph`'s prime-factorization integer — replaced by adjacency-list `question_edges` table\n- `SprintOrchestrator`'s Gödel-number-per-session state — replaced by Axiomatic summary chain\n- Implicit BIGINT circuit breaker — replaced by Cognitive Gas (see Phase 2 — Cognitive Gas track)\n\n## Key files\n\n- `lib/sfl/compiler/workflows/sprint_workflow.rb` — existing Achilles→Tortoise→Crab→Genie pipeline; needs an intermediate-Genie trigger mode\n- `lib/sfl/compiler/question_graph.rb` — Phase 1; to be superseded (not deleted in Phase 2, kept as reference)\n- New: `lib/sfl/compiler/workflows/rolling_synthesis_workflow.rb`\n- New: `lib/sfl/compiler/jobs/intermediate_genie_job.rb`\n- DB migration: `question_edges` table (adjacency list: `parent_id → child_id, depth`)\n\n## Validation target\n\nSingle 10,000-word document: confirm Axiomatic summary preserves SFL metadata and stance filters operate on summarized evidence identically to raw clause evidence.
