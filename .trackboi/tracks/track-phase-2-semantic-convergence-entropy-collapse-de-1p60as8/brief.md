## Problem\n\nA reasoning loop that revisits the same evidence, rephrases the same argument, or cycles through equivalent clauses without making progress is stuck. In Phase 1, this manifests as the Gödel BIGINT ceiling being hit before the spin is noticed. In Phase 2 (unbounded depth), a stuck loop can run indefinitely without a convergence detector.\n\n## Pattern\n\nSemantic Convergence uses the pgvector embedding space already deployed for hybrid retrieval to detect entropy collapse:\n\n1. Periodically embed the reasoning loop's current Axiomatic summary\n2. Compare cosine similarity to the previous checkpoint embedding\n3. If similarity > configurable threshold (e.g. 0.97): the loop is producing semantically identical output → entropy collapse detected\n4. Force circuit break: halt loop, emit current Axiomatic summary as final result, write audit log entry (similarity score, cycles elapsed, clauses consumed)\n\n## What it replaces\n\n- Gödel number's implicit overflow circuit breaker (system halted because integer could not grow, not because reasoning converged)\n- Phase 2's equivalent risk: unbounded loop with no termination condition\n\n## What it preserves\n\nAll existing pgvector infrastructure. No new embedding model, no new vector index. `Embedder` class (`lib/sfl/compiler/retrieval/embedder.rb`) and the ivfflat cosine index on `embeddings` table are reused. Same embeddings that power `HybridRetriever`'s semantic search now also power reasoning-loop health monitoring.\n\n## Key files\n\n- `lib/sfl/compiler/retrieval/embedder.rb` — reused, no changes\n- New: `lib/sfl/compiler/convergence_detector.rb` — checkpoint + cosine comparison + audit log\n- `lib/sfl/compiler/sprint_orchestrator.rb` — wire convergence detection into halt predicate\n\n## Validation\n\nDeliberately stuck loop (one that rephrases the same argument): confirm cosine threshold triggers circuit break and audit log captures the event with similarity, cycle count, and clauses consumed.
