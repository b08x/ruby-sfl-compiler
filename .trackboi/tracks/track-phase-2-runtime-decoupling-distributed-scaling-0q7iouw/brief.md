## Clarification: this is NOT the TUI segfault fix\n\nThe single-threaded PyCall constraint caused the TUI segfault (`BatchApp` running spaCy on a background thread). That is architecturally resolved by Gush/Sidekiq — each `CompileTurnJob` runs in a separate OS process with its own Python interpreter. Track 8 (TUI overhaul) wires the fix into the UI. This track is about something different.\n\n## What this track is actually about\n\nAt Phase 2 scale (enterprise corpora, Rolling Synthesis with intermediate Genie syntheses), Pass 1 and Pass 2 need to scale independently. The in-process PyCall bridge couples them into a single Ruby process — you cannot run 50 Pass 1 workers on spaCy-optimized machines and 20 Pass 2 workers on GPU-accelerated LLM machines without decoupling the runtimes.\n\n## Pattern\n\nReplace `PassOneEngine`'s direct PyCall invocation with a client that speaks to a standalone syntactic service. Feature-flagged via `SYNTACTIC_SERVICE_URL` env var — when set, use the remote service; when absent, fall back to the existing PyCall path. This allows incremental migration without a flag day.\n\n## Candidate service approaches (from docs/architecture.md)\n\n- **HTTP microservice**: Flask/FastAPI wrapper around spaCy, returns `SyntacticClause[]` JSON\n- **gRPC**: Lower overhead for high-volume, typed protobuf schema matches `SyntacticClause` shape\n- **Language-native parser**: Ruby-native NLP (eliminating Python dependency entirely) — highest effort, lowest operational complexity\n\n## Key files\n\n- `lib/sfl/compiler/pass_one/pass_one_engine.rb` — add `SYNTACTIC_SERVICE_URL` branch\n- New: `lib/sfl/compiler/pass_one/syntactic_service_client.rb`\n- New: `services/syntactic_service/` (Python FastAPI or Rack-based)\n\n## Prerequisite\n\nRolling Synthesis requires concurrent intermediate Genie syntheses — which require concurrent Pass 1 and Pass 2 operations. The current single-process PyCall architecture (even with Gush parallelism via separate processes) has operational scaling limits at extreme volume. This track removes that ceiling.
