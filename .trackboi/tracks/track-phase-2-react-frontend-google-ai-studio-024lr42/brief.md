## Goal\n\nThe architectural-lineage doc and modular-integration guide position this project as middleware for external RAG pipelines. The React frontend is the demonstration surface that makes the Safe RAG hypothesis *visible* — not just measurable in spec output but interactive and comprehensible to stakeholders who need to see why stance-filtered retrieval changes the answer.\n\n## Primary view: Safe RAG Hypothesis Validator\n\n```\n┌─────────────────────────────────────────────────────────────┐\n│  Query: [___________________________________]  [Submit]      │\n│  Stance filters: modality ▏████░░░░▏ tenor ▏██████░░▏       │\n│                                                              │\n│  WITHOUT filters              WITH filters                   │\n│  ┌────────────────────┐      ┌────────────────────┐         │\n│  │ Evidence [1-5]     │      │ Evidence [1-3]     │         │\n│  │ (includes low-     │      │ (high modality +   │         │\n│  │  modality clauses) │      │  formal register)  │         │\n│  ├────────────────────┤      ├────────────────────┤         │\n│  │ LLM Answer         │      │ LLM Answer         │         │\n│  │ (may absorb        │      │ (filtered evidence,│         │\n│  │  persuasive stance)│      │  objective facts)  │         │\n│  └────────────────────┘      └────────────────────┘         │\n└─────────────────────────────────────────────────────────────┘\n```\n\n## Secondary views\n\n- **Corpus browser**: ingested documents, per-clause SFL annotations, annotation_source provenance\n- **Analysis dashboard**: conversation/documentation analysis results (tenor timeline, speaker profiles, correlation heatmap)\n- **Workflow monitor**: live Gush/Sidekiq workflow status (consuming `GET /workflows/:id/status`)\n\n## API dependency\n\nAll data via Falcon HTTP API. No direct DB access from the frontend. CORS policy: development localhost, production domain.\n\n## Build toolchain\n\nGoogle AI Studio scaffolding → Vite + React. TailwindCSS for layout. Recharts for tenor timeline / correlation visualizations.
